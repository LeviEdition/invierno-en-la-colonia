## 1. Resumen ejecutivo

Se ratificó que **V9.9 ya es una referencia mecánicamente suficientemente fiel a *Dead of Winter*** para los objetivos del proyecto. No se necesita una nueva auditoría general de fidelidad. La vía técnica debe seguir **D1/D2**, preservar la referencia y solo después introducir cambios propios.

Se abrió una **hoja de ruta singleplayer** (documento [63](63-hoja-de-ruta-planificacion-singleplayer.md)) para separar la planificación conceptual del trabajo técnico. La sesión se concentró en **SP-02, economía de acciones y especialización de personajes**. Al estudiar una posible tercera estadística se investigaron variantes de dados por atributo inspiradas en sistemas de reserva de dados, y luego un sistema híbrido. Se construyeron laboratorios aislados y se ejecutaron simulaciones exploratorias.

**Reflexión final del creador:** como primer videojuego, es preferible **examinar la posibilidad de conservar las mecánicas de V9.9 y priorizar la identidad narrativa**, evitando rediseñar combate, dados, progresión y narrativa simultáneamente. **Esto quedó como orientación recomendada, no como cambio irreversible aprobado.**

**Compromiso de continuidad:** **mañana, jueves 29/10/2026, retomamos SP-02**. No se salta automáticamente a SP-05 ni se inicia implementación del modo propio.

## 3. Qué se estudió en SP-02

1. **Especialización:** las estadísticas, pasivas, equipamiento, ubicación y estado del superviviente deben generar decisiones tácticas genuinas. No imponer topes de dados para forzar participación equitativa. Catálogo V9.9 revisado: ataque, búsqueda, influencia, pasivas de búsqueda, combate, construcción, curación, movimiento seguro, ahorro de comida y resistencia.
2. **Tercera estadística:** se compararon movilidad, técnica, resistencia y operaciones/oficio. Criterio central: justificar una nueva estadística solo si produce decisiones recurrentes con peso similar a ataque y búsqueda.
3. **Mecánica alternativa de dados:** se exploró separar economía de acciones de resolución mediante pools de d6 por atributo, con éxitos graduados. Propuesta ilustrativa: tres supervivientes → tres órdenes de grupo, sin dados iniciales; ciertas acciones requieren pruebas según stat. No se aprobó.
4. **Híbrido contextual:** se evaluó resolver directamente acciones de rutina o defensas preparadas, reservando pruebas para acciones inciertas. Otra hipótesis: combate determinista con exposición posterior para preservar riesgo.
5. **Reconsideración de alcance:** las variantes de reglas se conservarán como documentación e investigación, pero la primera entrega jugable podría mantener esencialmente V9.9 y diferenciarse por el Director, los personajes, las campañas y las consecuencias diferidas.

## 4. Laboratorios y hallazgos

Se trabajó con **maquetas separadas del motor completo V9.9**, no con partidas reales comparables del producto final.

- **Primer banco:** **480.000 rondas exploratorias**. Con cuatro acciones y efectos básicos, cumplimiento de metas **V9.9 simplificado / pool puro**: medicamentos **81,87 % / 71,16 %**, asedio **83,17 % / 43,76 %**, laboratorio **81,87 % / 61,57 %**. Se detectaron sesgos en exposición, configuración de personajes, consecuencias y planes fijos; **no son tasas de victoria del V9.9 completo**.
- **Banco híbrido:** **750.000 rondas simuladas**, 25 condiciones × 3 sistemas × 10.000. Con igual presupuesto: medicamentos **81,87 % / 71,16 % / 71,16 %**, asedio **83,17 % / 43,76 % / 62,33 %**, laboratorio **81,87 % / 61,57 % / 71,16 %** (clásico simplificado / pool / híbrido).
- **Hallazgo crítico de híbrido:** al fortificar primero, la maqueta permitió **100 %** de cumplimiento de objetivo de asedio con Damián porque un ataque determinista no producía desgaste ni riesgo; **no demuestra supervivencia ni diversión**. La exposición tras combate podría devolver tensión, pero la referencia V9.9 puede ser letal (1/6 de mordedura por exposición), de modo que tampoco se adoptó sin pruebas.
- **Lectura transversal:** cambiar simultáneamente número de órdenes, movimiento, exposición y recompensa invalida una comparación causal simple. Más dados lanzados o más grados de éxito no equivalen automáticamente a más estrategia. Las simulaciones sirven para detectar defectos y generar hipótesis; no sustituyen pruebas humanas ni evaluación narrativa.

**Resultado de ingeniería de esta exploración:** prototipos/laboratorios aislados, informes y datos de análisis; **ningún cambio al motor ejecutable V9.9 por estas propuestas**.
